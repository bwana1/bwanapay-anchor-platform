# Conviction Markets Submission Context

BwanaPay is a Zambia-first cross-border payments project using anchor-based architecture on Stellar. This repository contains the local development implementation used to validate core anchor flows before testnet deployment.

The deeper problem we are encountering is the pre-commercialization funding and coordination gap for regulated financial infrastructure in frontier markets. Builders can now produce working technical prototypes quickly, but traditional equity is often premature before formal counterparties are secured, while grants typically support experimentation without solving ownership, verification, or long-term deployment incentives.

BwanaPay is a concrete case study. We have demonstrated local SEP-1, SEP-10, and SEP-24 anchor flows and gathered 93 early expressions of interest from users with cross-border payment exposure. The next challenge is coordinating milestone-based capital, trust signals, compliance support, and counterparties before conventional venture or institutional structures fully fit.

This maps directly to Conviction Markets themes including funding without equity, trust without institutions, verification without managers, coordination without companies, and discovery and matching.
